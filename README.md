Сборка из исходников:
# 1. Клонируйте репозиторий
git clone [<URL-репозитория>](https://github.com/segaTk/Sound-Bar.git)
cd folder

# 2. Соберите релиз-версию (оптимизированную)
cargo build --release

# 3. Запустите игру
# Windows:
.\target\release\guitara-sound-mod.exe
# Linux/macOS:
./target/release/guitara-sound-mod
